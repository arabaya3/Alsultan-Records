# StudioOS V22 — تثبيت الإدارة وحماية التشغيل

- إصلاح زر **تحويل الحجز إلى مناسبة** الذي كان ظاهراً في V21 بدون دالة تنفيذ.
- إنشاء المناسبة من الحجز كمسودة خاصة افتراضياً لحماية الخصوصية.
- منع تعطيل الحساب الإداري المستخدم حالياً من الواجهة.
- قاعدة البيانات تمنع تعطيل أو تخفيض صلاحية آخر Super Admin فعّال.
- تشديد رفع الصور العامة: يجب ربطها بمناسبة عامة ومع وجود موافقة نشر.
- تنظيم مسارات الصور العامة داخل `events/<event_id>/...`.
- Rollback لملف التخزين إذا فشل إنشاء سجل media.
- إظهار أخطاء حذف ملفات التخزين بدلاً من تجاهلها.
- تحسين جدول المستخدمين وتوضيح الحساب الحالي.
- تحديث وسم نسخة النسخ الاحتياطي إلى StudioOS V22.
