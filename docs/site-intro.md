# افتتاحية السلطان (Site intro)

- **الملفات:** `web/src/components/layout/SiteIntro.tsx` (markup + سكربت inline صغير)، أنماط `.site-intro` في `web/src/app/globals.css`، تُعرض فقط داخل `(public)/layout.tsx`.
- **السلوك:** اللوغو الأصلي ثابت وحلقة ذهبية تدور حوله، ثم «فرحتك إلها حكاية.»، ثم فتحة دائرية تكبر من المركز وتكشف الصفحة. المدة الكاملة ≤ 2 ثانية (إزالة مضمونة عند 2.05s)، بدون صوت أو وميض.
- **مرة واحدة بالجلسة** (`sessionStorage["sultan-intro-v1"]`): لا تتكرر عند التنقل أو التحديث.
- **«تخطّي»** يعمل فورًا حتى قبل hydration.
- **prefers-reduced-motion أو بدون JS:** الموقع يظهر مباشرة.
- **الصفحة تُحمَّل خلفها** بدون انتظار مصطنع. بعدها لا يبقى overlay، ولا قفل scroll، ولا عنصر يعترض النقر (`pointer-events:none` من 1.6s).
- **لا تظهر** في الإدارة ولا في صفحة الدخول.
