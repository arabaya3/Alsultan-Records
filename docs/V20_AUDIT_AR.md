# StudioOS V20 — تدقيق التطوير من الجذور

## ما تغير فعلياً

### 1) الواجهة العامة
- إلغاء الاعتماد على صورة الغلاف القديمة في الواجهة الرئيسية.
- Hero جديد بالكامل مبني على هوية الاستوديو نفسها وليس على صورة Banner محمّلة بالنص.
- نظام Typography جديد: Alexandria للعناوين وIBM Plex Sans Arabic للنصوص.
- إعادة بناء التسلسل البصري، المسافات، الأزرار، الأقسام، والخدمات.
- تقليل استخدام البطاقات المتكررة واستبدال جزء كبير منها بمسارات تحريرية وصفوف خدمات وBento مدروس.
- Responsive كامل للموبايل والتابلت والشاشات الكبيرة.
- حركة خفيفة مع احترام prefers-reduced-motion.

### 2) الهوية
- لوحة ألوان Black / Warm Gold أكثر هدوءاً.
- استخدام الشعار كعنصر هوية مركزي بدل صورة Profile غير مناسبة.
- إزالة استخدام صورة الغلاف القديمة من Hero والمعرض الافتراضي.
- توحيد أسلوب الأزرار، الحواف، التباين، والعناوين.

### 3) تجربة العميل
- الصفحة الرئيسية أصبحت تقود العميل من: تعريف > خدمات > نوع المناسبة > طريقة العمل > الأعمال > مخطط التغطية > الطلب.
- نموذج الطلب ما زال مرتبطاً بـ StudioOS/Supabase.
- فحص التاريخ، تتبع الحجز، الشكاوى، وبوابة العميل بقيت محفوظة.
- العروض والتقييمات الديناميكية لا تظهر كمساحات فارغة إذا لم يكن هناك محتوى منشور.

### 4) لوحة الإدارة
- تحديث كامل لواجهة StudioOS بصرياً بدون تغيير وظائف الإدارة الحالية.
- تحسين الجداول، النماذج، Metrics، MFA/Login، والشريط الجانبي.
- الحفاظ على أدوار super_admin/admin/staff/customer ومسار MFA.

### 5) الأمان والمتانة
- تحديث CSP للسماح بالخطوط الجديدة مع إبقاء القيود الأمنية.
- إضافة visible focus واضح للوصول بلوحة المفاتيح.
- حماية أفضل من XSS في نتائج التتبع وبوابة العميل عبر escaping للبيانات المعروضة.
- admin وportal ما زالا noindex/no-cache.

### 6) Cloudflare / Routing
- إضافة wrangler.jsonc صريح لـ Workers Static Assets.
- html_handling = auto-trailing-slash.
- not_found_handling = 404-page.
- إنشاء Alias folders لكل صفحة، خصوصاً /admin/ و/portal/، مع بقاء admin.html وportal.html موجودين.
- هذه الطبقة تقلل احتمال تكرار مشكلة 404 لمسارات HTML عند اختلاف طريقة النشر.

## أمور لا يصح ادعاء اكتمالها قبل الإنتاج
- TURNSTILE_SECRET يجب أن يكون مضبوطاً داخل Supabase Edge Function Secrets.
- يجب إجراء Live QA بعد نشر V20 على Cloudflare.
- أرشيف الصور الحقيقي يحتاج مواد فعلية من أعمال الاستوديو؛ V20 لا يضع صوراً وهمية بدلاً منها.
- سياسة الخصوصية والشروط مسودات تشغيلية وتحتاج مراجعة قانونية محلية قبل اعتمادها النهائي.
- ربط Custom Domain وتحليلات Search Console/Analytics مرحلة إنتاج مستقلة.
