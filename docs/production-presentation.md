# تحسين العرض ضمن تصميم الإنتاج (fix/production-presentation)

- **الأساس:** `c015839`، وهو آخر `master`.
  - commit النشر الفعلي على Vercel لم يُتحقق منه مباشرة، لأن ربط Vercel يحتاج إعادة تفويض.
  - المؤشر المتاح: CSP الموقع الحالي لا يحوي أي إضافة من تجربة الاستوديو الملغاة، و`master` لم يتغير منذ 2026-10-24.
- **النطاق:** عرض فقط. لا migration، ولا تغيير بيانات أو أسعار أو اشتراكات، ولا ريلز أو فيسبوك. ترتيب الألبومات والتواريخ والهيرو والريلز في فرع منفصل: `feature/album-publishing-reels`.

## ما تغيّر

| الجزء | التغيير |
|---|---|
| صفحة العرض | الوصف يُعرض أقسامًا. كل خدمة مرقّمة بطاقة فيها بنودها، وكل سطر قصير يسبق قائمة يصبح عنوانًا لها. |
| «التسليمات والهدايا» | قسم مميّز، فقط حين يكتبه المالك بنفسه. |
| توزيع الصفحة | عمودان على الكمبيوتر، وعمود واحد على الهاتف. بلا عمود فارغ حين لا توجد صورة. |
| رأس الصفحة | السعر والفترة ومدة العرض بعناوين واضحة، مع زر واتساب. |
| الوصف الحر | يبقى نصًا منظّمًا بطول سطر مقروء. |
| أغلفة الألبومات | `srcset`/`sizes` بالعرض الحقيقي للعمود: نسخة 480px أو 1600px. الأغلفة كاملة (contain) كما كانت. |
| الرئيسية | الألبومات بعمودين على الهاتف. روابط «كل الألبومات» و«كل الأعمال» بنص ظاهر. |
| صفحة الألبوم | الصور أقرب للعنوان والأزرار. |

ما لم يتغير:
- النصوص والأسعار وحالة إظهار السعر وتواريخ العروض.
- الإيموجي المخزّن.
- المحلّل الأصلي `parseTextBlocks`. التجميع طبقة عرض فوقه.
- العارض: كان يتلاشى عند الفتح ويحترم تقليل الحركة، فلم يُعدّل.

- **العَرَض:** صفحة العرض الجديد أعادت 404.
- **السبب:** الصفحة تقرأ قائمة العروض المخزّنة (`getOfferBySlug` → `getActiveOffers`، بـ `cacheLife("minutes")`).

- **الإصلاح:** الاختبار ينتظر حتى تظهر الصفحة، بنفس أسلوب `offers.spec`. لم تُخفَّف أي توقعات.

**إخفاق V1:**
- **السبب:** ملفات اختبار محلية غير متتبَّعة في git (`.cache/upload-fixtures` و`raw-samples`) لم تكن في الـ worktree الجديد.

**اختبار UA1:** عُدّل فحص البنية من «قائمة مرقّمة واحدة» إلى «بطاقة لكل خدمة»، لأن المتطلب نفسه تغيّر. فحص ظهور كل سطر بقي كما هو.
